## Iteration log

- **baseline** — plasma4 `mobile.html`. It is scored with the same suite as the iOS build (T35–T37 were run separately and merged in).
- **iter1** — first iOS build (28 evals). Failures:
  - T17 was a real bug. With a safe area, the game canvases were sized for the whole window, so taps landed about 75px away from the cookie. Fixed by re-running the resize callbacks after the safe-area adjustment.
  - T19, T23 and T27 were bugs in the evals themselves:
    - T19: a save import legitimately unlocks achievements, so the eval now compares against plasma4's export of the same save.
    - T23: `goldenClicks` only counts the spawn lead, so the eval now counts pops.
    - T27: Chromium sends a stray `mouseover` to (0,0) after a tap.
  - Also fixed: the tooltip now closes on its own instead of waiting for the next `tooltip.update`.
- **iter2** — added evals T29–T37. Changes in this version:
  - Golden cookies pop on `pointerdown`.
  - Service worker warm-up, so the app can relaunch offline.
  - Copy / Paste buttons for moving saves.
  - Repair for the standalone keyboard shrink.

  T37 failed: Chromium also shrinks `screen.height` when the window is resized, so screen size alone could not detect the stuck viewport.
- **final** — the app now remembers the full height for each orientation before the keyboard is ever shown, with `screen` as a fallback. 37/37 pass.
